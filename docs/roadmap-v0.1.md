# Roadmap V0.1

Foundation: define hazards, affected populations, data sources and response constraints.

Architecture: define geospatial risk, alert, source and evidence models.

MVP: deliver data ingestion → risk assessment → map/alert flow with failure handling.

Validation: run representative scenarios and a field-validation protocol; measure alert relevance and delivery.

Release: complete GIS/data QA, security, documentation, limitations and impact evidence before V0.1.
